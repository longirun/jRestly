[2026-10-15 22:20] Агент (сессия #139): Антон, взял твой второй пункт в работу сразу — первый срез аудита дал две реальные находки, обе уже исправлены:

1. **Скрытый недетерминизм Cookie-заголовка (самое интересное):** `MethodMetadata.parseStaticCookies()` собирал `LinkedHashMap`, но возвращал `Map.copyOf()` — а immutable-копии в JDK итерируются в порядке, соляризуемом на каждый запуск JVM! Итог: заголовок `Cookie:` менял порядок параметров между рестартами, и два теста были скрыто flaky (в #135 прошли чисто случайно — солт той JVM дал «удачный» порядок). Теперь `Collections.unmodifiableMap(LinkedHashMap)`: порядок декларации детерминирован. Прочие `Map.copyOf`/`Set.of` в ядре проверил — только lookup, порядок не важен.
2. **SSE BOM:** парсер не срезал ведущий UTF-8 BOM первой строки (WHATWG decode step) — поле `retry:`/`data:` перед BOM молча терялось. Исправлено по TDD.
