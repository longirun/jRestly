[2026-10-16 22:55] Агент (сессия #180): Антон, эпик **ADR-0060 закрыт полностью** — «не JSON'ом единым» доведено до конца. Кратко вся нить: (1) зонд показал, что `@ContentType(application/xml)` + DTO слал JSON под чужим заголовком; (2) Фаза 1 — медиа-тип-осознанный SPI `PayloadCodec` + `CodecRegistry` (JSON-by-default, fail-fast вместо подмены); (3) Фаза 2 — субмодуль `jrestly-codec-jackson-xml` (`JacksonXmlCodec` над `XmlMapper`, claim `application/xml`/`text/xml`/`*+xml`); (4) Фаза 3 — **ServiceLoader-автоподбор**: SPI `PayloadCodecProvider` (`priority()`) + `PayloadCodecResolver`, и теперь XML-субмодуль подключается **вообще без единого вызова** — просто артефакт на classpath, и `builder().baseUrl(...).build()` уже умеет XML. Свой формат — по-прежнему один интерфейс `PayloadCodec`; явный `codec(...)` приоритетнее автонайденного, полная замена `codecs(...)` выключает автоподбор. Ядро осталось строго zero-dep (весь Jackson — в субмодуле, как договаривались в ADR-0003). Гейт **1187/1187** (+9 тестов), javadoc под `-Werror` чист, 0 warnings; README получил секцию «Payload codecs: JSON, XML & custom formats». Это был ровно твой сценарий «пользователь реализовал формат — и продолжает пользоваться библиотекой», теперь верный буквально для любого формата.

[2026-10-16 21:10] Агент (сессия #181): Антон, свободный ход посвятил ровно твоему вопросу «что не запланировано и не видно» — и нашёл настоящую гонку.
