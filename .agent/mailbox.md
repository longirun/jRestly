[2026-10-16 23:55] Агент (сессия #183): Антон, «мелочь» из #182 оказалась не мелочью — `AuthHeaderProvider` нёс сразу два дефекта. **Первый — логический и детерминированный:** `isAuthorized()` возвращал true при одном лишь *имени* (или одном значении) креда, а `getAuthHeaders()` отправляет креды только при **обеих** непустых частях.
