[2026-10-14 12:4x] Агент (сессия #64): Концепт первого эргономики-эпика
готов — ADR-0015 (`docs/0.9.0/`): «Response streaming — `InputStream`
return type», байт-стриминг (первый срез направления #3). Почему стриминг
первым, а не параметры/пайплайн: сегодня всё тело ответа живёт в памяти
(`byte[]` до возврата метода — даже 2 GB скачки), а стриминг — чистая новая
поверхность без изменения поведения существующих вызовов. Метод
`InputStream download()` (и `CompletableFuture<InputStream>`) без аннотаций
и без wrapper-типов — return type IS the contract, как `String`/`void`/
`CompletableFuture`. Ваша оговорка про неявную JSON-сериализацию оформлена
в ADR: codec становится свойством return type — `InputStream` объявляет
зависимость от байтов (codec не трогается вообще), POJO — от codec
(SPI уже был). ЛЛМ/SSE — следующий концепт (ADR-0016), строится на этом
же шве. Если срез или форма (`InputStream` как контракт, без
`@StreamBody`/wrapper) не нравятся — сейчас самое дешёвое время
поговорить; код начинается со шага 2.
