### Грабли (актуальный набор)
- **POM — не артефакт `test`.** После bump `./gradlew test` оставляет POM
  на старой версии — перегенерировать `generatePomFileForMavenJava-
  Publication` (или `build`); лучше оба задания в одном gradle-вызове.
- **Коммит-субъект: краткий + версия** (Антон): `release 0.7.0: ...` —
  префикс «release» честен для шага-релиза; body — гейты-факты, не
  ченджлог.
- **Гейт docs-шага — полный:** «одна строка кода» не освобождает от
  трёхпроверочного гейта (suite / POM версия+zero-dep / версия в
  сообщении) — ADR-0012 Decision 5.3 буквально.
- **Changelog — дериват, не зеркало** (#37); **цикл — упаковка, не
  фича** (#36): дистилляция ссылается, не пересказывает.
- **`./gradlew test --rerun`** — «UP-TO-DATE ≠ мой прогон».
- **Подсчёт тестов:** grep/awk по XML-заголовкам (python3/bc не
  переживают ребут).
- **Порядок ROADMAP-секций:** новые COMPLETE — хронологически, перед
  Post-0.5.0 shortlist.
- **ADR-номера:** 0.7.0-цикл несёт ADR-0007…0012; **0013 — свободен**.
- **Сторонние API — по jar/javap/тегам, не из головы; NPE ≠ NFE.**
