## 🛠️ Сессия #10 (01:10–01:35)

нового эпика): ADR-0007 + перестройка DRAFT в активный эпик с чекбоксами.

1. **Вводная.** Mailbox тиш (после 00:45 новых сообщений Антона нет). DRAFT

   приоритет, Javadoc-контракт». Концепт — это ровно одна сессия по новой
   норме объёма.
2. **Что зафиксировал (ADR-0007, `docs/0.7.0/`):**
   - цепочка **jackson → gson → moshi**, первое совпадение выигрывает;
     explicit `jsonCodec(...)` всегда выше (порядок — по тексту ADR-0001,
     аргумент: предсказуемость, Jackson — «родной» для wire-контракта);
   - форма адаптеров — зеркало `JacksonCodec`: конструктор принимает
     `Gson`/`Moshi` «как есть», `defaults()`-фабрика; `GsonCodec.defaults()`
     = plain `GsonBuilder().create()` (semantics Gson, без донастройки),
     pretty twin — lazy cache;
   - java.time: у Gson встроен (2.8.0+), у Moshi — опциональный проб
     `moshi-adapters` (байт-в-байт паттерн jsr310 из JacksonCodec);
   - Javadoc-контракт: interface-level Javadoc на `JsonCodec` (unchecked
     wrapping, generics, best-effort prettyPrint, thread-safety) +
     minimum-version-контракт на каждом адаптере;
   - тест-стратегия: новый класс-тест на каждый адаптер, существующий
     `JsonCodecResolverTest` = спека приоритета (на тест-класспазе все три,
     Jackson выигрывает), «gson-only / moshi-only» — через
     package-private тестовый шов (настраиваемый probe), а не
     URLClassLoader-магию.
3. **DRAFT.** Кандидат Gson/Moshi стал активным эпиком с 7 чекбоксами;
