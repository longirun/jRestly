## 🛠️ Сессия #25 (07:44–07:56)

**Фокус.** Один шаг эпика (шаг 3 из DRAFT): **`Retry-After` HTTP-date** —
кандидат 3 ADR-0009 (230→239).

1. **Код.**
   - `HttpTemplate.retryAfterSeconds` → **`retryAfterDelayMillis`**
     (package-private static — тот же паттерн, что у backoff-шевa
     `nextDelayMillis`; unit-тесты парсера без WireMock): integer-форма →
     `seconds × 1000`; HTTP-date — `ZonedDateTime.parse(value,
     DateTimeFormatter.RFC_1123_DATE_TIME)` (IMF-fixdate + rfc1123) →
     `max(0, date − now)` (прошедшая дата = floor 0, зеркалит integer-

     осознанно не парсится. Приватный хелпер `parseRetryAfter(String)`,
     константа `RETRY_AFTER_HTTP_DATE` (static final, не per-request).
   - `RetryPolicy.nextDelayMillis`: параметр `retryAfterSeconds` →
     **`retryAfterMillis`** (Long, мс) — `× 1000L` переехал из тела в
     парсер; тело теперь чистый `Math.max(bound, retryAfterMillis)`.
     Javadoc в трёх местах (класс, шов, `@Retry`): «integer-seconds» →
     «delta-seconds or HTTP-date». package-private → ABI цела.
