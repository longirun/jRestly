Входящие: юбилейная сотая сессия! Кандидат №1 из активной зоны DRAFT.md — вектор зрелости №3 от Антона: элегантный доступ к метаданным заголовков (пагинация Link, ETag, Location, rate limits) при строгом соблюдении ADR-0004 (никакого `Response<T>`).

Ход: концепт и ADR-0022, реализация `ResponseHeaders` с RFC 8288 link parser и capture pattern, интеграция в пайплайн, unit и WireMock интеграционные тесты.

- **Концепт и архитектура (ADR-0022):**
  - Создан `docs/0.10.0/ADR-0022-response-headers-and-metadata-access.md`.
  - Статус **Accepted**: zero-dep доступ к метаданным заголовков без изменения принципа прозрачных методов.
  - Двойной эргономический доступ:
    1. Неаннотированный параметр `ResponseHeaders` в сигнатуре метода интерфейса:
       `List<Item> getItems(@RequestParam("page") int page, ResponseHeaders headers)`.
    2. Zero-signature capture pattern для нетронутых интерфейсов:
       `CapturedResponse<List<Item>> resp = ResponseHeaders.capture(() -> client.getItems(1))`.
  - RFC 8288 Web Linking parser: извлечение target URI по relation (`link("next")`, `links()`), поддержка multi-link, unquoted `rel`, space-separated relations.
  - Доступ к `Location` (`location()`, `locationUri()`), `ETag` (`etag()`), `Content-Type` (`contentType()`), `Retry-After` (`retryAfter()`), `X-RateLimit-*` (`firstLongValue()`), длительности (`duration()`), HTTP статусу (`statusCode()`, `isSuccess()`).
- **Реализация:**
  - `ru.jrestly.http.ResponseHeaders`: потокобезопасный mutable-holder и value-container с lazy parsing ссылок и scoped capture `ThreadLocal`.
  - `ru.jrestly.http.CapturedResponse<T>`: неизменяемый record для пары `(result, headers)`.
  - `HttpTemplateBuilder`: метод `resolveResponseHeadersHolder()` находит и извлекает экземпляр `ResponseHeaders` из параметров метода без сериализации его в запрос.
  - `HttpTemplate`: поле `responseHeadersHolder`, популяция в `processResponse` до декодирования тела и уведомление активного `CURRENT_CAPTOR` (работает и для успешных ответов, и для `@OnError` / `UnexpectedStatusException`).
  - `ControllerValidator`: параметр `ResponseHeaders` признан intrinsic library hook и исключен из подсчета payload-параметров для multipart/form-urlencoded.
- **Тесты (+18 новых тестов, всего 483/483 в 57 классах):**
  - `ResponseHeadersTest` (8 unit тестов в `ru.jrestly.http`): unpopulated defaults, case-insensitive headers, numeric long headers, multi-value headers, RFC 8288 multi-link parser, unquoted rel, space-separated relations, Retry-After (seconds & RFC 1123 date), capture pattern lifecycle & exception cleanup, ControllerValidator rules.
  - `ResponseHeadersWireMockTest` (9 E2E WireMock интеграционных тестов): RFC 8288 пагинация через параметр метода, пагинация через `ResponseHeaders.capture`, создание ресурса 201 Created с `Location` и `ETag`, рейт-лимиты `X-RateLimit-*`, async `CompletableFuture<T>` twin, streaming `InputStream`, ошибки `@OnError` (`TestErrorDto`) и `UnexpectedStatusException`, null-safety opt-out.
