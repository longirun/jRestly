# jRestly Feature Backlog

Canonical feature inventory for porting from `jrestly-infinite` (`ba68f1f`) into `main`.

### Invariants & Quality Gates
1. **Zero Runtime Dependencies:** Root artifact `ru.jrestly:jRestly` must contain 0 `<dependency>` tags in generated POM.
2. **Atomic Commits:** `1 feature = 1 commit` (`feat(<scope>): ... (ADR-xxxx)`) accompanied by unit/integration tests and ADR.
3. **Controlled Convergence:** `infinite` (`ba68f1f`) is the reference quarry. Intentional divergence is permitted when improving design, fixing defects, or refining APIs during review (documented in the corresponding ADR).
4. **Test Gate:** Suite green (`./gradlew test`) at every commit. Versioning is determined in `main` during delivery.
